# Der Zauberkönig / The Wizardking

Play: https://stbange.github.io/wizardking-play/

Built files only (source revision 236610b). Desktop: WASD + mouse, left click cast,
right click melee, Space jump, Shift sprint, F/Ctrl dodge, 1-4 / Q / E / wheel spells,
Esc/P pause, F1 Deutsch/English. Touch controls switch on
automatically on phones and tablets. ?lang=en for English, ?seed=XXXXXXXX for a seed.
